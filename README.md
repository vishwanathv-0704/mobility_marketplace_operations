# Mobility Operations Intelligence

A Python Flask-based mobility data validation and operations analytics platform.

## Features

- Upload Drivers, Trips, and Driver Activity CSV files
- Data validation and error detection
- Trip anomaly detection
- Driver, trip, and zone analysis
- Operational insights generation
- Web-based dashboard

## Tech Stack

- Python
- Flask
- Pandas
- HTML/CSS
- Pytest
